# Fox Girl Companion (Fabric 1.20.1)

Лисичка-компаньон для выживания. Модель и текстура — твои (Fox Girl 3.2), читаются прямо из
`assets/foxgirl/bbs/foxgirl.json`, так что конвертировать ничего не нужно.

## Как собрать
1. Нужны JDK 17 и интернет.
2. Положи в папку проекта Gradle wrapper (скопируй `gradlew`, `gradlew.bat` и папку `gradle/`
   из https://github.com/FabricMC/fabric-example-mod) или выполни `gradle wrapper --gradle-version 8.5`.
3. `./gradlew build` -> готовый мод в `build/libs/foxgirl-1.0.0.jar`
   (или `./gradlew runClient`, чтобы сразу запустить игру).
4. Для игры нужны Fabric Loader и Fabric API для 1.20.1.

## Как играть
- Яйцо призыва: вкладка «Яйца призыва». Дикие лисички изредка появляются в лесах и тайге.
- Приручение: давай любую еду (шанс 1/3 за кормление). Ягоды и жареное мясо её приманивают.
- ПКМ пустой рукой — сесть / идти следом.
- Сытость падает на 1 в минуту. Пока сыта — защищает тебя, лечит (регенерация, когда у тебя ≤ 50% HP)
  и ночью подсвечивает монстров поблизости. Голодная — слабеет и не помогает. Корми её!
- От криперов убегает, их не атакует.

## Настройка
Вся логика в `FoxGirlEntity.java` (константы вверху: сытость, интервалы, здоровье).
Анимации — в `FoxGirlModel.setAngles`.
